Shipping an order

Status changes follow paid → shipped → delivered. Pending orders are awaiting confirmed payment and cannot be shipped.

  1. Wait for the payment confirmation to mark the order paid. Orders with a refund cannot be fulfilled.
  2. Enter the tracking number below and save the order.
  3. Return to the orders list, select the order, choose “Mark selected paid orders shipped” in Actions, and click Go.
  4. After delivery, select “Mark selected shipped orders delivered” from the same list.
